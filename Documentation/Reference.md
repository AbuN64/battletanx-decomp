# Reference

## Rules
- External decomp C MAY be studied and used as a starting point for BattleTanx, but landed C MUST meet this repo's bar: untouched compiler and n64link output exact, full ROM `make check` exact, zero asm labels, no fake types, casts or views.
- BattleTanx code, commits and README MUST NOT carry provenance lines or mentions naming an external reference decomp.
- Names and structure from an external reference MUST go through the Recipe naming conventions of this repo.
